# Cowboy Truck Stop 2

Website for Cowboy Truck Stop 2 — a 24-hour Mobil stop on I-20 in Marshall, Texas, with Desi Dhaba inside.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/about` — About the stop
- `/eat` — Desi Dhaba
- `/services` — Fuel, workshop, restrooms, Wi-Fi, store, parking
- `/contact` — Hours, phone, map
